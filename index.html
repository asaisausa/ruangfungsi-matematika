01

Operasi Aljabar Fungsi

Penjumlahan, pengurangan, perkalian, dan pembagian fungsi.

Konsep dasarnya

Fungsi bisa diperlakukan seperti bentuk aljabar. Kalau ada dua fungsi, misalnya f(x) dan g(x), kita dapat menggabungkannya dengan operasi hitung. Kerjakan bentuk fungsi seperti biasa, tetapi perhatikan tanda kurung dan nilai yang membuat penyebut nol.

Penjumlahan
(f + g)(x) = f(x) + g(x)
Pengurangan
(f − g)(x) = f(x) − g(x)
Perkalian
(f · g)(x) = f(x) · g(x)
Pembagian
(f / g)(x) = f(x) / g(x), dengan g(x) ≠ 0
Ingat: pada pengurangan, tanda di dalam fungsi kedua ikut berubah. Pada pembagian, nilai yang membuat g(x) = 0 tidak boleh masuk domain.
✓ Contoh soal & pembahasan

Diketahui dua fungsi

f(x) = 2x + 3 dan g(x) = x − 1

Tentukan (f + g)(x), (f − g)(x), (f · g)(x), dan (f / g)(x).

1

Penjumlahan(f + g)(x) = (2x + 3) + (x − 1)= 2x + x + 3 − 1 = 3x + 2

2

Pengurangan(f − g)(x) = (2x + 3) − (x − 1)= 2x + 3 − x + 1 = x + 4

3

Perkalian(f · g)(x) = (2x + 3)(x − 1)= 2x² − 2x + 3x − 3 = 2x² + x − 3

4

Pembagian(f / g)(x) = (2x + 3) / (x − 1)Syarat: x − 1 ≠ 0, jadi x ≠ 1.

Hasil:
(f + g)(x) = 3x + 2
(f − g)(x) = x + 4
(f · g)(x) = 2x² + x − 3
(f / g)(x) = (2x + 3)/(x − 1), x ≠ 1

Latihan mandiri

Coba dulu, baru buka jawaban

1. Diketahui f(x) = 3x + 2 dan g(x) = x − 4. Tentukan (f + g)(x).

Lihat kunci & cara singkat

(3x + 2) + (x − 4) = 4x − 2

Gabungkan suku sejenis: 3x + x = 4x dan 2 − 4 = −2.

2. Jika f(x) = 2x − 1 dan g(x) = x + 3, tentukan (f · g)(x).

Lihat kunci & cara singkat

(2x − 1)(x + 3) = 2x² + 6x − x − 3

Jadi, hasilnya 2x² + 5x − 3.

3. Tentukan (f / g)(x) jika f(x) = x² − 4 dan g(x) = x − 2.

Lihat kunci & cara singkat

(x² − 4)/(x − 2) = ((x − 2)(x + 2))/(x − 2) = x + 2

Syarat dari fungsi awal tetap berlaku, yaitu x ≠ 2.

02

Komposisi Fungsi

Menyusun dua fungsi menjadi satu fungsi baru.

Apa itu komposisi fungsi?

Komposisi fungsi berarti memasukkan hasil dari satu fungsi ke fungsi lain. Bayangkan fungsi pertama sebagai mesin yang mengolah angka, lalu hasilnya dimasukkan lagi ke mesin kedua.

f dikerjakan setelah g
(f ∘ g)(x) = f(g(x))

Hitung g(x) terlebih dahulu, lalu masukkan hasilnya ke f.

g dikerjakan setelah f
(g ∘ f)(x) = g(f(x))

Hitung f(x) terlebih dahulu, lalu masukkan hasilnya ke g.

Penting: urutan berpengaruh. Pada umumnya (f ∘ g)(x) ≠ (g ∘ f)(x). Perhatikan fungsi yang berada di dalam tanda kurung.
🧠

Trik membaca: (f ∘ g)(x) dibaca “f komposisi g dari x”. Huruf yang di dalam dikerjakan lebih dahulu.

✓ Contoh soal & pembahasan

Tentukan kedua komposisi

f(x) = 2x + 1 dan g(x) = x² − 3

A. Cari (f ∘ g)(x)

1

Gunakan bentuk f(g(x)).f(g(x)) = 2g(x) + 1

2

Ganti g(x) dengan x² − 3.= 2(x² − 3) + 1 = 2x² − 5

(f ∘ g)(x) = 2x² − 5

B. Cari (g ∘ f)(x)

1

Gunakan bentuk g(f(x)).g(f(x)) = (f(x))² − 3

2

Ganti f(x) dengan 2x + 1.= (2x + 1)² − 3 = 4x² + 4x − 2

(g ∘ f)(x) = 4x² + 4x − 2

Latihan mandiri

Komposisi

1. Diketahui f(x) = 3x + 1 dan g(x) = x². Tentukan (f ∘ g)(x).

Lihat kunci & cara singkat

f(g(x)) = 3g(x) + 1 = 3x² + 1.

Masukkan fungsi g ke tempat x pada fungsi f.

2. Jika f(x) = x − 2 dan g(x) = 2x + 5, tentukan (g ∘ f)(x).

Lihat kunci & cara singkat

g(f(x)) = 2f(x) + 5 = 2(x − 2) + 5 = 2x + 1.

03

Fungsi Invers

Mencari fungsi yang membalik proses fungsi awal.

Pengertian dan syarat

Fungsi invers adalah fungsi yang mengembalikan keluaran ke masukan semula. Jika fungsi f mengubah x menjadi y, inversnya mengubah y kembali menjadi x.

Notasi invers
f⁻¹(x)

Dibaca “f invers”, bukan satu dibagi f(x).

Syarat umum
f(f⁻¹(x)) = x

Agar invers juga menjadi fungsi, fungsi awal harus satu-satu (bijektif pada domain dan kodomain yang ditetapkan).

Cara menentukan invers

1

Misalkan y = f(x).

2

Tukar posisi x dan y.

3

Selesaikan persamaan hingga y berdiri sendiri.

4

Ganti y menjadi f⁻¹(x).

Catatan: fungsi seperti f(x) = x² tidak memiliki invers yang berupa fungsi jika domainnya semua bilangan real. Jika domain dibatasi menjadi x ≥ 0, inversnya bisa berupa √x.
✓ Contoh soal & pembahasan

Tentukan invers dari

f(x) = 3x − 6

1

Ubah fungsi menjadi y = 3x − 6.

2

Tukar x dan y.x = 3y − 6

3

Jadikan y sebagai subjek.x + 6 = 3yy = (x + 6)/3

4

Ganti y menjadi f⁻¹(x).

f⁻¹(x) = (x + 6)/3
🔎

Cek hasil: f(f⁻¹(x)) = 3((x + 6)/3) − 6 = x. Hasilnya kembali ke x, berarti sesuai.

Latihan mandiri

Fungsi invers

1. Tentukan invers dari f(x) = 2x − 7.

Lihat kunci & cara singkat

y = 2x − 7 → x = 2y − 7 → x + 7 = 2y

Jadi, f⁻¹(x) = (x + 7)/2.

2. Jika f(x) = (x + 4)/3, tentukan f⁻¹(x).

Lihat kunci & cara singkat

y = (x + 4)/3 → 3y = x + 4 → x = 3y − 4

Setelah menukar variabel, diperoleh f⁻¹(x) = 3x − 4.
